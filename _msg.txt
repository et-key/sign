docs: §4 のシグネチャ表を通した（幽霊語を落とし、実装と突き合わせた）

記法だけが `List` = `Array | Struct` としており、**同じ語が表の中で2つの意味で
使われていた**。

  | `,` | 中置 | (L -> R) -> List |            ← Struct を含むつもり
  | `~` | 後置 | Deref(... -> (List | Struct | Atom)) |  ← 別物として並べている

`List` と `Struct` を分けるのは幅が揃うかどうかであり（§2）、渡し方も違う
（`List` は `{ptr, len}`、`Struct` は `{ptr}`、stack_abi.md §4.6）。同じ語で2つを
指すと、Pass 4 がどちらの命令を出すか決まらない。`Array` はこの1行にしか出て
こない語だった。同じく `Register`（2箇所）と `Number`（表では2箇所）も、Layer 2 に
存在しない語である。

全ての行を**実装と突き合わせてから**書き換えた。

  `,`         -> List                              →  -> (List | Struct)
  ` ` 空白    Atom | List                          →  Atom（List ⊂ Atom）
              -> (List | Lambda | __)              →  -> (List | Struct | Lambda | __)
  `'` `@`     Implicit(Atom | List | Lambda)       →  Implicit(Atom | Lambda)
  `~` 後置    Deref(-> (List | Struct | Atom))     →  Deref(-> Atom)
  `<<` `>>`   (L(Address | Register) -> Number)    →  (L(Address | Int) -> Int)
  `||` `;;` `&&`  (L(Address | Register) -> Scalar) →  (L(Address | Int) -> (Address | Int))
  `!` 後置    Number -> Number                     →  L(Scalar) -> L
  `?`         (List -> R)                          →  (List(Identifier) -> R)

`Atom | List` が冗長になったのは、`Atom` を Layer 1 の語（値ならなんでも）へ戻した
結果である。旧定義（`Scalar | String`）では `List` を明示的に足す必要があった。

階乗は `Int -> Int` にしかけたが、`5.0!` が `Float` を返すことを確かめて `L(Scalar) -> L`
にした——他の算術と同じく左辺が域を決める。`5 !` は空白があると中置として読まれて
コンパイルエラーになる（`!` に中置は無い）ので、後置は `5!` と書く。

記法ブロックに `Struct` / `Deref` / `Identifier` の定義を足した。
