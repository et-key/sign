# 仕様定義

## 字句の定義
1. 字句素は、関数名、変数名、リテラル、演算子からなる
2. カッコは、`(`、`)`、`[`、`]`、`{`、`}`の6種類あり、これらは全て同義の字句素である
3. タブによるインデントのみを認める。スペースはタブの代用としない
4. 字句素は、空白によって区切られる
5. 文字列リテラルは、`` ` ``で囲むものとする
6. リテラルの対象となる空白は、字句素の区切りにならない
7. 文字リテラルの対象として記述される特殊記号は、`\`の後に記述する
8. 文字列リテラル内部ではエスケープシーケンスが不要である
9. 代わりに文字列と文字の結合を以て、文字列内にバックスラッシュや引用符、改行を記述する

## 構文の定義

1. この言語の構文は、式のみである
2. 式は、リテラル、識別子、演算子によって構成される
3. 式の区切りは改行である
4. 式のまとまりは、ブロックを使う
    1. ブロックの開始は、インデントを増やすことによって明示する
    2. ブロック内の式は、全て同じ深さのインデントを用いる
    3. ブロックの終了は、インデントを減らすことによって明示する
5. 演算子には、前置演算子、中置演算子、後置演算子がある
    1. 中置演算子は、対象値の間に配置し、空白で区切らなければならない
    2. 前置演算子は、対象値の直前に配置しなければならない（対象値との間を空白で区切ってはならない）
    3. 後置演算子は、対象値の直後に配置しなければならない（対象値との間を空白で区切ってはならない）
6. 演算子と関数
    1. 演算子の定義は演算子テーブルによる
    2. 演算子の優先順位は、演算子テーブルによる
